# Nils Rottstegge — Personal Website

Personal portfolio featuring selected work in high-performance computing, GPU
computing, sparse linear algebra, and adaptive methods. Includes project
demonstrations and a downloadable CV.

Built with Astro and TypeScript.

Website: [nilsrottstegge.com](https://nilsrottstegge.com/)

## Development

```sh
npm install
npm run dev
```

## Validation and build

```sh
npm run check
npm run build
```

## Deployment

GitHub Actions builds the website on pushes to `main` and publishes the generated
`dist/` directory to GitHub Pages. This README is not included in the published
website.
